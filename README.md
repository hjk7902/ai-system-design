  - JDK 25
  - Sprint Tools for Eclipse 5.1.1
  - Spring Boot 4.0.6
  - Spring AI 1.1.3, 2.0.0
## 파이썬
  - Python 3.13
  - VSCode
  - YOLO26
## MQTT 서버
  - Mosquitto
